相对 baseline

L1 与 L2 pilot 的 action match 均为 83.3%，高于 dev 多数类基线 33.9% / 32.7%。Base model 对应 action match 为 0% / 14.3%。方向正确，但生成样本只有 6 条。

早期统一 LoRA 对照

7 月 21 日统一控制器 pilot（173 train / 27 dev）JSON valid 只有 75%，eval loss 0.324。之后拆成五专家 LoRA，协议生成率在门禁样本上升到 100%，说明职责拆分至少改善了格式与动作可学性。

数据质量

格式与隔离质量较强，语义覆盖和类别平衡仍是主要短板。下面把“已经被自动门禁验证的”与“仍需实验回答的”明确分开。

已通过的硬质量项

全部 five-LoRA train/dev 行：assistant JSON parse 100%、chat role 合法 100%、prompt forbidden key 命中 0、eval-only 混入 train 为 0。最终包 gate 整体 passed。

数据隔离

manifest 以视频为单位分配角色；held-out 有 485 个视频。Video-Holmes test 全部保留为 held-out，训练侧只使用其 train 视频。当前报告未发现 unknown video（Motif 的 80 行为来源标签 unknown，需继续治理）。

长尾专家样本过少

Repair 57、Verifier 27 条 train，远低于 L1；容易记忆模板，无法覆盖真实失败分布。

类别失衡明显

Repair 主类占 98.2%，Verifier 主类占 88.9%；package gate 已要求训练时 family-weighted sampling。

质量指标偏结构化

现有 gate 重 JSON、动作名、泄漏与格式；缺少大规模语义正确率、最终答案正确率与跨数据集泛化。

后训练与下一步

后训练链路已经能跑，但目前规模只足以证明机制可用。最重要的下一步不是继续看 train loss，而是在冻结的 held-out 视频上建立 SFT → OPD/GRPO 的增量收益曲线。

GRPO 小规模验证

20 groups / 74 samples；label-diverse 85%，空答案 0，全部 20 组具有非平凡 advantage，mean terminal success 16.2%，采集质量门禁全过，已产出 L2+Repair adapter。

OPD 教师校准

62 条 ranking-Borda distill rows；顺序打乱后 top-1 一致率 100%，mean L1 0.077，校准门禁通过。此前 16 条 soft teacher 版本 top-1 仅 12.5%，已被排序/Borda 方案替代。

Motif 现状： 20 对 on/off QA 中，正确率均为 30%，delta correct = 0；开启 Motif 后 accepted-strong 从 55% 到 60%，但没有转化成答案正确率提升。这是“调用链可用、效用尚未证明”的明确信号。
P0 · 建立可信评测

在 held-out 485 视频上报告正确率、accepted-strong、abstain、repair conversion，并给置信区间。

P1 · 扩充弱专家数据

重点增加 Repair / Verifier 的困难负例与少数动作族；治理 Motif 80 条 unknown 来源。

P2 · 校验训练数值

GRPO 报告中的 mean KL 为负值（-0.223），与标准 KL 非负性质冲突；在扩大训练前应核对日志定义/实现。
